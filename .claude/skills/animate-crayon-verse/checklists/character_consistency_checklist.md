# Checklist: Konsistensi Karakter

Gunakan **§A** saat desain/model sheet, **§B** per shot (self-check animator), dan **§C** untuk gambar hasil AI.

## A. Desain dan model sheet
- [ ] Kepala lingkaran sempurna (shape primitif), Ø = 28–32% tinggi total
- [ ] Tinggi total 3–3,5 × Ø kepala (anak 2,5×)
- [ ] Tanpa leher; badan bean menempel di bawah kepala
- [ ] Badan bean lebar 0,9–1,1 × Ø kepala (varian gemuk terdokumentasi)
- [ ] Lengan dan kaki garis tunggal, tebal = outline
- [ ] Mata oval vertikal hitam di garis tengah; alis mengambang terpisah
- [ ] Outline `#1A1617`, 8–10 px @1080p, round cap
- [ ] Fill datar, 1 shadow sabit, tanpa gradien di karakter
- [ ] Kelas warna ditetapkan (hero/figuran/kerumunan)
- [ ] Siluet + 1–2 props identitas membedakan tokoh dari tokoh lain di video
- [ ] HEX lengkap: base/shade/highlight untuk kulit, rambut, pakaian
- [ ] Turnaround 5 view, 12 ekspresi, mouth chart, pose sheet tersedia
- [ ] Desain orisinal (bukan salinan tokoh/maskot channel referensi)
- [ ] Tokoh nyata: karikatur ringan, tanpa penghinaan fisik

## B. Per shot
- [ ] Ø kepala sesuai tabel shot size (`references/cinematography_and_composition.md` §1), dengan selisih ≤ ±3% dari shot lain dengan size sama
- [ ] Props identitas hadir (kacamata, kumis, topi, dasi…)
- [ ] Warna HEX identik dengan model sheet (atau tercatat dimodifikasi lighting pass)
- [ ] Ketebalan outline sama dengan shot lain walau ada scale/zoom
- [ ] Shadow sabit di sisi yang benar (berlawanan key light scene)
- [ ] Wajah bergeser ke arah hadap secara konsisten (tidak "melompat")
- [ ] Tidak ada morphing tak disengaja (kepala oval, badan menyusut)
- [ ] Ekspresi sesuai emosi naskah; alis terbaca tanpa mulut
- [ ] Maksimal 2–3 tokoh berwarna penuh di frame; kerumunan abu
- [ ] Kostum/props sama dengan shot sebelumnya dalam adegan yang sama

## C. Gambar/video hasil AI
- [ ] Kepala tidak oval, tidak ada hidung atau telinga realistis
- [ ] Tidak muncul leher atau bahu anatomis
- [ ] Lengan dan kaki tetap garis (bukan tabung bervolume)
- [ ] Jari tidak muncul (atau tepat 4 bila memang close-up tangan)
- [ ] Outline tidak menipis atau bervariasi liar
- [ ] Tidak ada gradien/tekstur di karakter
- [ ] Warna kulit dan rambut sama dengan model sheet
- [ ] Tidak ada teks acak/rusak di latar
- [ ] Video AI: tidak ada bentuk berdenyut/tekstur bergerak (temporal artifact)
