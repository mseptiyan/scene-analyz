# Checklist: Kualitas Scene (per shot, setelah compositing)

## Staging dan komposisi
- [ ] Satu titik fokus jelas; terbaca ≤ 1 detik tanpa suara
- [ ] Silhouette test lulus (aksi terbaca bila semua karakter hitam)
- [ ] Grayscale test lulus (tokoh fokus kontras nilai vs latar)
- [ ] Subjek di tengah/sepertiga sesuai tujuan; tidak ada tangensi canggung (tepi kepala menempel tepi objek/frame)
- [ ] Headroom/ruang untuk teks dialog tersedia
- [ ] Teks dan elemen penting di dalam title-safe 90%; pojok kanan bawah bebas teks penting
- [ ] Aturan 180°, eyeline, dan screen direction konsisten dengan shot sekitar
- [ ] Tidak lebih dari 3 shot berturut-turut dengan size + angle yang sama

## Latar dan depth
- [ ] Hue lokasi sesuai mood map dan sama dengan kunjungan sebelumnya ke lokasi ini
- [ ] Props latar sama dengan master BG lokasi (tidak pindah/hilang)
- [ ] Perspektif props dan BG benar
- [ ] Depth: FG framing/blur/desaturasi kerumunan sesuai kebutuhan
- [ ] Negative space bersih di belakang wajah tokoh fokus

## Lighting dan warna
- [ ] Satu arah key light; semua shadow sabit konsisten
- [ ] Rim/color cast sesuai sumber cahaya
- [ ] Overlay atmosfer tidak menutupi wajah atau teks
- [ ] Luminance dan saturasi sesuai grade sekuens
- [ ] Merah/hijau selalu disertai panah/label (aksesibilitas)

## Teks dan infographic
- [ ] Ejaan dan angka cocok dengan naskah final + sumber
- [ ] Font dialog/label/judul sesuai sistem; stroke kontras ≥ 4,5:1
- [ ] Teks bertahan ≥ 1 detik per 3 kata
- [ ] Tick/balon menunjuk ke pembicara yang benar

## FX
- [ ] FX mendukung aksi, tidak menutupi wajah tokoh utama
- [ ] Partikel tidak terlalu padat (risiko kompresi)
- [ ] Blur berat tidak ada di wajah

## Integrasi
- [ ] Tidak ada clipping, objek melayang, atau kaki tanpa bayangan kontak
- [ ] Layering benar (lengan depan/belakang objek)
- [ ] Pose awal/akhir shot cocok dengan handoff shot berdekatan
