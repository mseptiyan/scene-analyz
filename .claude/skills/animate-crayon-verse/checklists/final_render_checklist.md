# Checklist: Final Render & Delivery

## Sebelum render
- [ ] Laporan QC full-pass: 0 temuan S1, 0 temuan A-S2, semua D tertutup
- [ ] Semua shot versi terakhir sudah di-conform (cek nomor versi di timeline)
- [ ] Tidak ada placeholder (panel storyboard, teks "TBD", watermark tool)
- [ ] Semua angka, nama, dan tanggal di layar sudah di-fact-check
- [ ] Lisensi musik, SFX, font, dan stok terdokumentasi
- [ ] Logo/merek pihak ketiga dipakai secara wajar (editorial) atau diganti generik
- [ ] Segmen sponsor dibungkus bumper dan diberi label bila perlu

## Video
- [ ] Resolusi 1920×1080 atau 3840×2160, 16:9, square pixel
- [ ] 24 fps konstan (tidak ada konversi fps campuran)
- [ ] Master ProRes 422 HQ / DNxHR HQ
- [ ] Versi upload H.264 High, 12–20 Mbps (1080p) / 35–45 Mbps (4K)
- [ ] Tidak ada frame hitam/flash frame di awal, akhir, atau antar-cut
- [ ] Ruang end screen 20 detik terakhir bersih

## Audio
- [ ] −14 LUFS integrated, true peak ≤ −1 dBTP
- [ ] VO jelas di atas musik di seluruh durasi (cek di speaker ponsel)
- [ ] SFX impact sinkron ±1 frame
- [ ] Tidak ada klik/pop, potongan audio, atau hening tak sengaja
- [ ] WAV 48 kHz 24-bit di master; AAC 320 kbps di versi upload

## Platform
- [ ] Upload private/unlisted, ditonton penuh di desktop dan ponsel
- [ ] Tidak ada blocking/banding berat pada blur, gradien, confetti
- [ ] Thumbnail 1280×720 < 2 MB, terbaca di 320×180 dan 168×94
- [ ] Thumbnail konsisten dengan model karakter di video
- [ ] Subtitle SRT cocok dengan VO final
- [ ] Judul, deskripsi (sumber), chapter timestamp siap

## Arsip
- [ ] Project file, aset, rig, font, lisensi, dan laporan QC diarsipkan di `09_delivery/` + backup
- [ ] Aset baru ditambahkan ke bank (karakter, props, BG) untuk episode berikut
